# Resplandor Floral - Página Web

Este proyecto contiene el código de la página web de **Resplandor Floral** (extraído y adaptado desde https://resplandor-floral.odoo.com/).

## 📁 Archivos incluidos

1. **`index.html`** (Versión principal y recomendada):
   - Código limpio, moderno y 100% responsivo (móvil y escritorio).
   - Tipografías originales de Google Fonts (`DM Serif Display` y `Questrial`).
   - Todo el catálogo de cremas faciales y precios ($30.000 - $48.000 COP).
   - Enlaces a todas las imágenes en alta resolución del sitio original.
   - Formulario interactivo de contacto y pedido en ventana modal.

2. **`odoo_original.html`**:
   - Código fuente HTML en bruto descargado directamente de Odoo.

## 🚀 ¿Cómo visualizar la página?
- Puedes hacer doble clic sobre `index.html` para abrirlo directamente en tu navegador favorito (Chrome, Edge, etc.).
- O en Antigravity IDE, puedes usar una extensión como "Live Server" para previsualizarlo en tiempo real.
